# W1M1 - mtcars 데이터셋 분석하기

R에 내장된 고전 데이터셋 `mtcars`(1974 Motor Trend, 32개 차종 × 11개 변수)를 pandas로
탐색하며 EDA 기본기를 익히는 미션입니다.

## 분석 흐름 (`mtcars.ipynb`)

1. **데이터 로드 및 기본 확인** — 누락된 컬럼명 보정, `info()`/`describe()`로 형태 파악
2. **추가 정보 탐색** — 변수별 분포와 결측 확인
3. **gear × am 조합별 빈도** — `pandas.crosstab`을 사용한 방법과 사용하지 않은 방법 두 가지로 구현해 비교
4. **컬럼별 히스토그램** — `subplots`로 한 화면에 배치
5. **변수 간 상관계수 탐색** — 상관이 높은 조합을 골라 산점도로 시각화

## 팀 논의 내용

- 마력(`hp`)과 다른 변수의 관계를 확인하면서, 마력·실린더 수 등이 **연비(`mpg`)에 미치는 영향**을
  통해 더 좋은 연비의 차를 설계하는 비즈니스적 가치로 연결할 수 있다고 보았다.
- **배기량-무게 / 배기량-실린더 / 무게-연비** 그래프를 그려 각 관계를 분석했다. 차량 연비는
  도메인 지식과 직결되는 영역이라, 데이터 분석을 통해 도메인 지식을 간접적으로 습득할 수 있었다.
- `qsec`(1/4마일 가속 시간) 평균을 시대 기준으로 놓고 보면 대부분 스포츠카였다. 이를 근거로
  **이 데이터셋이 애초에 연비 목적으로 수집된 데이터가 아닐 수 있다**는 추측도 함께 논의했다.
