팀 프로젝트로 **카카오프렌즈 스토어 리뷰 기반 차기 굿즈 컨셉 선정**을 진행했습니다.

## 2. 팀 프로젝트 — 카카오프렌즈 굿즈 컨셉 선정 (`kakao_goods/`)

### 2.1 비즈니스 문제 정의

자사에 여러 캐릭터가 있지만 **어떤 캐릭터를 어떤 방식으로 상품화할지에 대한 명확한 기준이
부족**하다. 내부 선호도나 기존 인기 이미지만으로 캐릭터를 고르면 실제 고객 반응과 맞지 않는
굿즈가 나올 위험이 있고, 실제로 시즌 한정 굿즈가 기대보다 낮은 완판율을 기록한 사례가 있었다.

핵심 문제는 "어떤 캐릭터를 메인으로 선정할 것인가"가 아니라 다음과 같이 정의했다.

> 고객이 각 캐릭터를 어떤 이미지와 감정으로 인식하고 있으며,
> 그 인식이 어떤 굿즈 컨셉으로 연결될 수 있는가?

**제약 조건** — 내부 판매·수익률 데이터에 접근할 수 없어, 공개된 카카오 공식 쇼핑몰의
베스트 상품 정보를 대체 지표로 사용했다. 이를 근거로 **춘식이**를 메인 캐릭터로,
대표성 비교를 위한 기준 캐릭터로 **라이언**을 채택했다. 리뷰는 각 상품을 리뷰 많은 순으로
정렬해 상위 10개 품목만 수집했다.

### 2.2 데이터 수집 (`kakao_goods/etl/extract.py`)

대상 사이트(`store.kakao.com/kakaofriends`)는 Angular 기반 SPA로 리뷰가 JS로 동적 로딩된다.

- 카테고리 페이지에서 카테고리별 상위 N개 상품 링크를 먼저 수집
- 각 상품 페이지에서 리뷰 탭 클릭 → '더보기' 반복 클릭 → 리뷰 텍스트/평점/작성일 수집
- Scrapy 기반 비동기 크롤링 + `scrapy-playwright`로 실제 브라우저 렌더링
- Twisted reactor는 프로세스당 1회만 시작할 수 있어, 링크 수집과 리뷰 수집을
  콜백 체이닝(`parse_category` → `parse_review`)으로 묶어 스파이더 하나로 처리

**Selenium → Playwright 전환**: Selenium은 수집 속도가 너무 느렸다. Playwright로 바꾼 뒤
기존에 한 상품 페이지 리뷰 수집에만 약 3분이 걸리던 것이, **약 3분 만에 전체 상품 작업이
완료**되는 수준으로 개선됐다. 프로토타이핑에 사용한 raw data는 1,826건.

### 2.3 데이터 변환 — 평점 대신 형태소 분석 + 감성분석 모델

평점만으로 긍정/부정을 나누면 편향이 생긴다.

1. **평점-텍스트 불일치** — "배송은 늦었지만 상품은 괜찮아요"는 평점 4점이지만 본문에
   부정 표현이 섞여 있다. 이 단어가 긍정 워드클라우드에 들어가면 실제 긍정 요인과 어긋난다.
2. **평점 인플레이션** — 형식적 만점 리뷰가 긍정 그룹에 과대 포함되어, 워드클라우드가
   진짜 만족 요인 대신 '좋아요', '감사합니다' 같은 상투어 중심으로 구성된다.

그래서 문맥을 파악하는 도구가 필요하다고 판단해 형태소 분석기를 도입했다.

**형태소 분석기 비교**

| 분석기 | 속도 | 정확도 | 특징 |
|---|---|---|---|
| Mecab | 매우 빠름 | 높음 | 실무에서 많이 사용, 대용량 처리에 적합 |
| Kkma | 느림 | 매우 세밀 | 품사 태그가 세분화되나 무거움 |
| Komoran | 보통 | 높음 | 사용자 사전 추가가 쉬워 도메인 특화에 유리 |
| Okt (구 Twitter) | 빠름 | 보통 | 설치 간단, SNS/구어체에 강하나 세밀도 낮음 |
| Kiwi (kiwipiepy) | 빠름 | 높음 | 커머스 텍스트 평가가 좋고 pip 설치 가능 |

**Mecab 채택 이유** — Double-Array TRIE 사전 구조로 사전이 커져도 조회가 거의
`O(문자수)`로 유지되고, 포인터 추적 대신 배열 연산이라 캐시 친화적이다. CRF + Viterbi
최단경로 탐색을 동적 계획법으로 한 번에 계산해 규칙 기반 재귀 탐색보다 연산량이 적으며,
C++ 네이티브 엔진 + 사전 컴파일된 Binary Dictionary라 대량 배치 처리 시 초기 로딩 이후
처리 속도가 일정하게 유지된다.

**채택 품사 조합** — `NNG`(일반명사), `NNP`(고유명사), `VA`(형용사), `XR`(어근),
`VV`(선별 본동사). 즉 **명사 + 형용사 + 어근 + 선별 본동사** 중심으로 키워드를 추출했다.

**감성분석 모델** — `jaehyeongAN/KoELECTRA-finetuned-sentiment-analysis`
(학습 데이터: 쇼핑리뷰 + 스팀리뷰 + NSMC). 추후 고도화 시에는 **KcELECTRA**를 백본으로
Noisy Text / User-generated Text에 특화되도록 추가 파인튜닝하는 방향을 고려했다.

| 캐릭터 | Positive | Negative |
|---|---|---|
| 춘식이 | 7,247 | 1,153 |
| 라이언 | 4,119 | 483 |

### 2.4 분석 결과 및 인사이트

1. **차기 십이간지 에디션** — 라이언 긍정 키워드에 '푸른뱀 복주머니', '데코인형' 등
   십이간지 관련 키워드가 확인된 반면 춘식이에서는 두드러지지 않았다. 라이언 시리즈의
   성공 사례를 벤치마킹해 차기 십이간지 에디션 메인 모델로 춘식이를 검토할 만하다.
2. **캐릭터 차별점** — 라이언은 '안전요정', '출산선물', '복주머니' 등 **의례적·선물용**
   맥락이 강하고, 춘식이는 '만족', '좋아함', '가습기', '수면바지' 등 **실생활 밀착형**
   카테고리와 연결된다. 춘식이는 실용적 라이프스타일 굿즈 확장에 강점이 있다.
3. **카테고리 만족도** — '베이비필로우' 비중이 가장 높아, 촉감·재질이 강조되는 상품군이
   춘식이 아이덴티티와 시너지를 낸다.

**개선 및 추가 분석 요청**
- 부정 키워드('가격', '약하다', '냄새')는 제품 컨셉을 저해할 수준은 아니나 원인 파악이 필요
- '냄새', '포장', '반품' 등이 **어떤 상품군에서 발생했는지** 구분되지 않는다.
  방향제라면 향 지속력 불만, 베이비필로우라면 제조·유통 과정 문제로 해석이 갈린다.
  → 부정 키워드를 상품 카테고리별로 세분화해 분석할 필요가 있다.

**기획 단계 비즈니스 가치의 재현 가능성** — 긍정 키워드는 굿즈 컨셉 방향 도출에 유효했다.
반면 부정 키워드는 대부분 수령한 제품에 대한 불만이라 컨셉 결정에는 도움이 되지 않았고,
품질·가격·배송·포장 등 **개선 포인트를 찾는 데** 더 적합하다고 판단했다.
